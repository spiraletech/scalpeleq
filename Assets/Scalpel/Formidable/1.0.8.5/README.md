# Scalpel EQ Formidable 1.0.8.5 material kit

This kit translates the approved Band Mode, Carve and Analyze renders into reusable, text-free production layers. The analyzer and lower control surface are deliberately separate optical systems: live graph information is never baked into the glass, and page controls are never baked into the OLED substrate.

- `f1085_lacquer_shell.png`: black lacquer enclosure master, 1670 × 942.
- `f1085_graph_glass.png`: neutral analyzer reflection/edge layer, 1529 × 392, straight alpha.
- `f1085_control_glass.png`: seamless lower OLED/touch-glass substrate, 1570 × 317.
- `f1085_band_*`: physical band-key interaction states.
- `f1085_tab_*`: physical page-key interaction states.

The red line is reserved for selected hardware keys and live measurement energy. Lower-screen selections remain white; inactive options remain graphite. Reflections use neutral silver only—no cyan cast, decorative neon, text, numbers, icons, or DSP state is embedded in any material asset.
