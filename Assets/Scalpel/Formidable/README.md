# Formidable skin — 1.0.7.1 development candidate

Supplied kit: `Scalpel_EQ_107_Formidable_Asset_Kit (1).zip`, source 1670×942.
The original metadata and tokens are retained alongside this file.

Only `FormidableShell.png` is embedded: an unchanged copy of MATERIAL_001,
a lettering-free 275×81 surface sample. The renderer mirrors and neutralizes
its relief once into an immutable software texture. This is a material layer,
never a picture of the interface. Knobs, screws, keys, labels and all data
remain live JUCE drawing and controls. Prototype sprites are not embedded.

The kit explicitly rejects its source's footer sponsorship plaque and vents,
and requires an upright wordmark. Neither the source composite nor its atlas
is embedded. The source shows eight boundary markers; the existing seven-band
engine and parameterized boundary handles remain authoritative.

Rendering owners: `ScalpelReferenceLayout.h` (coordinates), `ScalpelFinish.h`
(material primitives), `ScalpelUI105.h` (cached plates and meter presentation),
`SurgeryLookAndFeel.h` (native control styling), `RootsEditor.cpp` (layout and
cached analyzer glass). See `Docs/FORMIDABLE-1.0.7.1-REVIEW.md` for verification.
