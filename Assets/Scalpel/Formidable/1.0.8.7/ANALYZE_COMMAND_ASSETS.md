# ANALYZE — B COMMAND

Approved ANALYZE icon scale for Scalpel EQ 1.0.8.7.

- Heat Map and Freeze share a 64 x 64 logical transparent canvas.
- The visible glyph envelope is 56 px at the 1344 x 789 reference UI size.
- Optical stroke is approximately 2.5 px.
- Selected state is white; idle and hover states are controlled by runtime opacity.
- No tile, glow, underline, divider, or baked background is present in either asset.
- Visual Decay geometry and the black-glass panel are unchanged.

The 256 x 256 PNG files are 4x runtime masters. SVG files remain the editable source of truth.
