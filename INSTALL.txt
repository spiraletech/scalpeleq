Scalpel EQ 1.0.8.3 — Formidable calibrated graph and dynamics candidate — Windows x64 VST3

Close FL Studio and other DAWs before replacing the plugin.
Extract this ZIP. Copy the COMPLETE “Scalpel EQ.vst3” folder to:
  C:\Program Files\Common Files\VST3\
Keep its Contents\x86_64-win\Scalpel EQ.vst3 binary inside that folder.
Rescan plugins if your host requires it, then open Scalpel EQ.

This is a controlled-development candidate, not a promoted stable release.
It uses the existing Scalpel plugin identity, parameter IDs and state format.
Keep your previous working Scalpel EQ.vst3 bundle so you can restore it.
The ZIP contains a Windows plugin, not source code or a mockup.

The approved 1.0.7.7 chassis, geometry, materials, controls and menu layout
remain protected. All seven established BAND 1–7 tabs and graph regions are
visible in a new session. Each region has two frequency magnets; drag either
magnet to resize, or drag anywhere inside the translucent colored region to
move the whole region without changing its logarithmic width.

The factory bands touch at the original 1.0.7.7 frequency boundaries.
Drag a shared seam to resize both bands. Drag the colored interior to move a
band or linked group at fixed width. Neighboring bands yield on contact so the
graph stays contiguous, with no same-domain overlap or reordering.

Right-click a present band or its BAND tab to remove it or unlink an explicit
magnetic relationship. Right-click a removed band's tab and choose ADD BAND to
restore it. If its range is occupied, the nearest editable band can give up
space. Double-clicking free graph space can also recreate a removed slot.
BAND OFF continues to apply spectral removal. Ctrl-drag a magnet to bypass snap.

Visual Decay reaches and displays a true 0.00; at zero, the displayed
measurement follows the current analyzer frame without retained falloff.

BAND OFF now uses high-rejection interval-wide filtering with click-safe live
boundary transitions, and respects the selected Stereo/Mid/Side domain.

Automated Windows VST3 and pluginval results are reported separately.
FL Studio 25 verification must be performed in FL Studio; a generic test host
is not a substitute for FL Studio project recall/playback/removal testing.




1.0.8.3 checks
- MASTER STEREO plays the full mix, MID plays the center, and SIDE plays the
  difference signal. Right-click a band to set its independent EQ domain.
- BAND PEAK holds the maximum reading for each band. RESET clears all band
  holds and the master output peak.
- The right graph ruler is the measured output in dBFS. The left ruler is
  the selected band's signed EQ target in dB. BAND GAIN reaches ±60 dB at
  the calibrated band center, with shaped shoulders between band edges.
- COMP THRESHOLD 0 dB uses a -18 dBFS detector reference. -9 dB lowers it
  to -27 dBFS for more peak reduction. +9 dB raises it to -9 dBFS and adds
  up to 9 dB of quiet-signal lift. Review existing offset automation because
  1.0.8.2 used the opposite sign for peak control.
- COMPRESSOR RATIO sets the band's compressor slope. AUTO recalls the
  original 4:1 for 176E and 6:1 for CE1B.
- PHASE CORRECTION estimates coherent L/R phase near the stereo band's
  geometric center and rotates the channels in opposite directions.
  MID and SIDE bands keep their independent routing.
- COMPRESSION offers OFF, 176E and CE1B. New instances start in OFF.
- The COLOR page and its sound coloration are removed. Legacy parameter IDs
  still load so existing projects retain a readable state.
- Set COMP OFF and enable a CARVE to test real cut and boost from -40 to +40 dB.
- BAND OFF mutes the assigned frequency region. BAND SOLO auditions it.
