Scalpel EQ 0.2.0 - Windows x64 VST3 development build

Close the DAW, then copy the COMPLETE Scalpel EQ.vst3 folder into:
C:\Program Files\Common Files\VST3
Rescan plugins and verify Scalpel EQ 0.2.0 in the host plugin information.
This is a separate plugin from Surgery EQ. Do not overwrite Surgery EQ.

There are no jukebox bars on the sides or external animated rails.
X-RAY changes only graph presentation; the accurate FFT trace remains.
COLOR has five independent per-band controls; zero is neutral.
FIELD selects STEREO, MID or SIDE for the selected band.
COMP AMOUNT increases clockwise. Select 1176 E 4:1 for FET compression.
PHASE is a conservative per-band stereo anti-correlation guard.
LIMIT enables an LA-2A-inspired optical leveler, not a brickwall limiter.

CARVE depth supports -90 to +90 dB. Existing preset meaning is preserved:
positive DEPTH cuts, negative DEPTH boosts. Zero is neutral.
The expanded depth parameter range changes normalized host automation scaling;
verify old depth automation lanes when migrating from 0.1.x development builds.
Physical depth values in plugin presets retain their meaning.

4K means verified 3840x2160 editor renders and native material buffers.
It does not certify 60 FPS or photographic parity with reference images.
Supplied lower-resolution references are not advertised as 4K masters.
Sound/pitch colors are designed correspondences inspired by synesthesia,
not universal biological frequency colors or solfeggio effects.

Unsigned development build. See docs/SCALPEL_0.2_ENGINEERING.md for validation,
removal-safety changes and remaining physical DAW acceptance checks.
