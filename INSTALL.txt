Scalpel EQ 1.0.7.8 — magnetic patch R3 candidate — Windows x64 VST3

Close FL Studio and other DAWs before replacing the plugin.
Extract this ZIP. Copy the COMPLETE “Scalpel EQ.vst3” folder to:
  C:\Program Files\Common Files\VST3\
Keep its Contents\x86_64-win\Scalpel EQ.vst3 binary inside that folder.
Rescan plugins if your host requires it, then open Scalpel EQ.

This is a controlled-development candidate, not a promoted stable release.
It uses the existing Scalpel plugin identity, parameter IDs and state format.
Keep your previous working Scalpel EQ.vst3 bundle so you can restore it.
The ZIP contains a Windows plugin, not source code or a mockup.

The approved 1.0.7.7 chassis, geometry, materials, controls and menu layout
remain protected. All seven established BAND 1–7 tabs and graph regions are
visible in a new session. Each region has two frequency magnets; drag either
magnet to resize, or drag anywhere inside the translucent colored region to
move the whole region without changing its logarithmic width.

The seven factory regions begin with deliberate logarithmic gaps so the
colored interiors are immediately draggable. Every magnet uses the same
horizontal rail. A connected boundary is one fused, two-color magnet rather
than two coincident dots.

Right-click an existing region to REMOVE BAND or explicitly unlink either
linked magnet. No audio, domain, compressor or color controls are duplicated
in that graph menu. Removal hides the region and magnets but keeps its BAND slot. Double-
click legal empty graph space to recreate a removed slot. Removal is separate
from BAND OFF: BAND OFF remains high-rejection spectral removal. Ctrl-drag a
magnet for precise unsnapped adjustment.

Snapped shared boundaries are real serialized relationships. Moving the
colored interior of a connected band moves the connected group as one rigid
unit and stops it at a spectrum edge or an unconnected same-domain region.
Cross-domain Stereo/Mid/Side overlap remains legal.

Visual Decay reaches and displays a true 0.00; at zero, the displayed
measurement follows the current analyzer frame without retained falloff.

BAND OFF now uses high-rejection interval-wide filtering with click-safe live
boundary transitions, and respects the selected Stereo/Mid/Side domain.

Automated Windows VST3 and pluginval results are reported separately.
FL Studio 25 verification must be performed in FL Studio; a generic test host
is not a substitute for FL Studio project recall/playback/removal testing.
